##  1. Детальний опис ідеї проєкту

**LifeSync** — це універсальний таск-менеджер для розмежування навчання, роботи та особистого життя. Усі справи в додатку обов'язково містять одну з трьох категорій:
* **Навчання** (лабораторні, сесія, курсові, читання статей);
* **Робота** (звіти, проєкти, дедлайни клієнтів);
* **Особисте** (спорт, шопінг, відпочинок, зустрічі з друзями, побут).

### Ключовий функціонал:
1. **Головний екран (Dashboard):** Містить кругову діаграму, яка аналізує тільки виконані справи за обраний період (день, тиждень, місяць).
2. **Оцінка складності та Календар:** Під час створення завдання користувач обирає складність за шкалою від 1 до 5 (1 — «легке», 5 — «важка справа»). Застосунок розраховує суму балів складності всіх завдань на кожен конкретний день та відображає їх у календарі за допомогою кольорової градації:
   *  **Зелений колір (1–4 бали):** Легкий день, оптимальне навантаження.
   *  **Жовтий / Помаранчевий колір (5–8 балів):** Середній день, вимагає концентрації.
   *  **Червоний колір (9+ балів):** Важкий / Критичний день, перевантажений дедлайнами.
3. **Менеджер завдань:** Зручна сторінка керування списками справ з фільтрацією за категоріями та складністю.
4. **Авторизація:** Сторінка входу та реєстрації користувачів.

##  3. Структура проєкту

```text
LifeSync/
├── .husky/            - Конфігурація Git-хуків для автоматичної перевірки коду
├── cypress/           - Налаштування та файли End-to-End (E2E) тестів
├── design/            - Матеріали дизайну, макети UI/UX
├── node_modules/      - Залежності та зовнішні бібліотеки проєкту
├── public/            - Статичні ресурси застосунку які доступні безпосередньо
├── src/               - Основний вихідний код React-застосунку.
│   ├── assets/        - Внутрішні статичні медіафайли
│   ├── components/    - Загальні UI-компоненти повторного використання
│   ├── features/      - Модулі функціоналу застосунку
│   │   ├── auth/      - Модуль авторизації та аутентифікації користувачів
│   │   ├── calendar/  - Модуль інтерактивного календаря
│   │   ├── main/      - Головна панель керування 
│   │   └── tasks/     - Модуль управління завданнями 
│   ├── pages/         - Компоненти сторінок які збирають компоненти.
│   ├── App.css        - Локальні стилі для головного компонента App.
│   ├── App.jsx        - Головний компонент верхнього рівня, який об'єднує маршрутизацію та базову розмітку
│   ├── App.test.jsx   - Модульний (Unit) тест для перевірки рендерингу компонента App за допомогою Vitest
│   ├── index.css      - Глобальні стилі застосунку
│   ├── main.jsx       - Точка входу React-застосунку, де відбувається монтування App у DOM-дерево
│   └── setupTests.js  - Конфігураційний файл середовища тестування Vitest
├── .gitignore         - Файл із переліком папок та файлів, які Git повинен ігнорувати
├── .prettierrc        - Налаштування форматування коду для Prettier
├── cypress.config.js  - Головний конфігураційний файл інструменту E2E-тестування Cypress
├── eslint.config.js   - Налаштування правил та стандартів написання коду для ESLint
├── index.html         - Головний HTML-шаблон, у який Vite вбудовує React-застосунок
├── package-lock.json  - Файл фіксації точних версій усіх встановлених npm-пакетів та їхніх залежностей
├── package.json       - Метадані проєкту, перелік установлених бібліотек та скрипти запуску
├── README.md          - Головний документаційний файл проєкту з описом
└── vite.config.js     - Конфігурація середовища розробки та бандлера Vite
